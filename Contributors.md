In order to ensure we're all on the same page, we're going to do a basic
Github exercise. Your job will be to add your name to this list of
contributors, confirming that you know how to commit changes.

For simplicity, there is no need to make another branch. Branches may be
useful when we start proper development, but for something this simple it is
unnecessary. Just commit directly to main when adding your name.

If needed, take some time to further familiarize yourself with Github. Proper
usage will be essential to a well-made project. There are tons of tutorials
and guides out there.
